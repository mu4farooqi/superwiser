# Browse by Tag

Show all tags and their counts from captured rules.

## Instructions

Call the `list_tags` MCP tool from superwiser.

**Important**: Do not display the raw JSON result from the tool. Present the tags in a clean table format with columns for Tag and Count.

To filter rules by a specific tag, the user can use: `/superwiser:search #<tagname>`
