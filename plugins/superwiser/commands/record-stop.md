---
description: "Pause recording preferences (persists across sessions)"
---

Pause Superwiser preference recording for this project. This persists across sessions.

## Instructions

Call the `disable_recording` MCP tool from superwiser.

Tell the user:
- Recording is now paused for this project
- This will persist across sessions
- Use `/superwiser:record` to resume recording
- Existing preferences are preserved and searchable
