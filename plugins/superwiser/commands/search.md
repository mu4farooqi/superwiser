# Search Preferences

Search your recorded coding preferences and decisions.

## Usage

```
/search <query>
```

## Examples

```
/search typescript
/search testing
/search authentication
/search code style
```

## Instructions

Call the `search_preferences` MCP tool from superwiser with the user's query.

Show the results to the user in a readable format.
