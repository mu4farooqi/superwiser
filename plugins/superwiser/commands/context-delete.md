---
description: "Delete a rule group by context ID"
---

Remove a rule group and all its rules from the database.

## Usage

```
/superwiser:context-delete <context_id>
```

## Instructions

The context_id is a 6-character alphanumeric ID like `x7k9m2`.

Call the `delete_context` MCP tool from superwiser with the provided context_id.

Confirm the deletion to the user.
