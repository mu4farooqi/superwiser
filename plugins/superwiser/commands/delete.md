---
description: "Delete a rule by ID"
---

Remove a rule from the database.

## Usage

```
/superwiser:delete <rule_id>
```

## Instructions

The rule_id is a 6-character alphanumeric ID like `x7k9m2`.

Call the `delete_rule` MCP tool from superwiser with the provided rule_id.

Confirm the deletion to the user.
